# Digital Image Processing Lab - MCA Semester II

This repository contains Digital Image Processing practical programs developed for MCA Semester II.

## Technologies Used
- Python
- OpenCV
- NumPy
- Matplotlib

## Practical List
1. Image Enhancement Techniques
2. Histogram Equalization
3. Gray Level & Bit Plane Slicing
4. Smoothing Spatial Filters
5. Gaussian, Laplacian & High-Boost Filters
6. Frequency Domain Filters
7. Edge Detection using Sobel, Prewitt & Roberts

## Features
- GUI-based image selection
- Visualization using Matplotlib
- Well-structured practical programs
- Easy to understand for students
